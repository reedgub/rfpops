# /onboard

Set up your agency profile through a guided conversation.

## Usage
/onboard

## What it does
Walks through 8 questions to capture your agency's:
- Company name and description
- Core services
- NAICS codes
- Certifications
- Typical contract sizes
- Recent wins (3 examples)
- Team clearances
- Hard no-go criteria

After the conversation, generates the four profile files in profile/.
