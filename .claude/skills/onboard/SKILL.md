# Onboard Skill

Guides a new user through agency profile setup via a structured conversation.

## Inputs
- Interactive user responses to 8 prompted questions

## Process
1. Present questions one at a time covering: company description, core services, NAICS codes, certifications, contract size range, three recent wins, clearance posture, and hard no-go criteria
2. Validate and confirm responses before proceeding
3. Generate profile file content from collected answers

## Outputs
- profile/capabilities.md — capabilities statement
- profile/past-performance.md — past performance entries
- profile/team.md — key personnel bios
- profile/disqualifiers.md — hard no-bid criteria list
