# Product Decisions

## Web App First

The core product risk is trust in the bid/no-bid evaluation, not browser convenience. The web app owns profile, past performance, evaluations, compliance matrices, outcomes, analytics, and workspace settings.

## Extension Second

The extension is the habit layer. It catches users while they browse SAM.gov and procurement portals, then sends page content into the same scoring flow.

## No Full Proposal Drafting

RFPOps is not positioned as proposal writing software. The MVP includes draft scaffolds only after the bid decision, because compliance, strategy, and pursuit discipline are the wedge.

## No Broad Free Tier

The MVP is designed for paid pilots and design partners. Broad free use would create low-signal usage before the scoring workflow is calibrated against real customer decisions.

## Outcome Tracking Is Core

Every bid/no-bid decision should produce learning. RFPOps records final human decision, influence, submission status, outcome, loss reason, hours spent, notes, and whether the user would make the same decision again.
